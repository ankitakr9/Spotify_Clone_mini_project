# Spotify_Clone_mini_project
# 🎵 Spotify Clone (HTML & CSS)

A simple and responsive *Spotify web player clone* built using *HTML and CSS, and deployed on **Vercel*.  
This project is created to practice front-end development and UI design.

👉 *View Live Project:https://spotify-clone-mini-project-rq6s.vercel.app/

## 📌 Features

- 🎧 Spotify-inspired UI
- 📱 Responsive design
- 🎨 Clean and modern layout
- 🖥️ Built using only HTML & CSS
- ☁️ Deployed on Vercel

## 🛠️ Technologies Used

- *HTML5*
- *CSS3*
  - Flexbox
  - Grid
  - Media Queries
- *Vercel* (for deployment)
